# 04 · 版本演进

仓库保留 v1 与 v2 两份独立源码。它们不是分支关系，而是同一项目的两个时间切片：v1 记录最初可运行的形态，v2 是对它的工程化重构。两者可分别编译运行，互不依赖。

## 逐项对比

| 维度 | v1（初始版） | v2（重构版） |
|---|---|---|
| 代码规模 | 233 行 | 1296 行 |
| 文件 | `src/v1/ShapeCalc.cpp` | `src/v2/ShapeCalc.cpp` |
| 图形类型 | 6 类 | 15 类规则图形 + 手绘多边形 |
| 计算指标 | 6 项（每图形仅面积） | 44 项 + 手绘 2 项 |
| 窗口尺寸 | 390 × 460 | 920 × 620 |
| 界面风格 | 纯色背景、直角矩形按钮、宋体 | 渐变背景、圆角卡片与投影、微软雅黑 + ClearType |
| 输入方式 | 连续弹出 `InputBox`，每参数一次 | 面板内表单，键盘直接录入 |
| 结果呈现 | 单个数字（`%.4f`），需另点「显示结果」 | 多指标列表，计算后立即显示 |
| 输入校验 | 无（`sscanf` 返回值未检查） | 空值/非正数/几何条件逐项校验，字段标红 |
| 错误语义 | 依赖 `result < 0` 与全局字符串 `"Error"` | 计算函数返回布尔 + 具体错误文案 |
| 架构 | 6 个平行函数，按钮坐标硬编码在 16 行重复绘制语句里 | `ShapeDef` 表 + 函数指针，循环渲染 |
| 状态管理 | 全局 `a,b,c,h,r,Text,result` | 收敛为 `g_valid` / `g_results` / `g_inputs` |
| 退出方式 | `exit(0)` 直接终止进程 | 置 `running = false`，正常退出并 `closegraph()` |
| 新增图形成本 | 改函数 + 改 3 处界面代码 | 加 1 个函数 + 1 行表项 |
| 编译告警（`/W3`） | 2 条 `C4244` | 0 |
| 产物大小 | 约 56 KB | 约 65 KB |

## 演进动因

### 1. 输入流程割裂

v1 每个参数都要弹出一次模态对话框，求一个三角形的四个量需要点击 4 次（三次输入 + 一次「显示结果」），且弹窗期间无法看到已填值，填错只能重来。

v2 改为面板内的固定表单：点击图形后光标自动落在第一个字段，`Tab` 顺次切换、`Enter` 直接出结果，全程不离开键盘。

### 2. 扩展方式不可持续

v1 的每个图形对应一组硬编码的按钮矩形与绘制语句，加一个图形要同步修改按钮表、`button_judge` 的判断链、点击分支、绘制语句四处，且 16 行 `rectangle` / `drawtext` 完全重复。

v2 把这些收敛进描述表：界面由表数据生成，事件按 `paramCount` 自适应，新增图形不再触碰界面代码。

### 3. 缺陷与误导性输出

v1 存在三处影响正确性的问题，v2 一并修复：

| 问题 | v1 表现 | v2 处理 |
|---|---|---|
| 菱形面积公式错误 | 按 `a × b` 计算（漏除以 2），输入对角线 3、4 得 12 而非 6 | 改为 `d1·d2/2`，并额外给出边长与周长 |
| 三角形非法三边未被拦截 | 海伦公式对不满足三边关系的输入取 `sqrt` 得 `NaN`，而 `if (s < 0)` 对 `NaN` 恒为 `false`，最终显示 `-nan` | 在开方前判断 `a+b>c` 等三边关系，直接返回「无法构成三角形」 |
| 悬停高亮残留 | 鼠标从一个按钮快速滑到另一个时只绘制新高亮、未擦除旧高亮，旧按钮保持反色 | 切换前先还原上一个按钮，再绘制新按钮 |

此外 v1 的 `scanf` 类调用不检查返回值，非数字输入会沿用上一次的全局变量值，v2 通过「输入即校验 + 非法标红」消除这条路径。

## v1 的保留价值

- **功能基线**：作为最小可运行实现，说明 6 类图形与事件循环的基本思路，便于理解 v2 的重构起点
- **对照样本**：同题不同解，可用于说明「表驱动 vs 硬编码」在扩展成本上的差异
- **可回归**：v2 的几何函数与 v1 对应函数语义一致（除菱形修正），两者的计算结果可互相验证

## 兼容性说明

两版共用 `third_party/easyx` 与同一套 `run.bat`，编译参数一致：`/EHsc /MD /O2 /W3`，多字节字符集（不定义 `UNICODE`）。

v1 保留 2 条 `C4244` 告警（`float s = sqrt(...)` 等处的 double→float 隐式转换），这是初始代码的真实状态，未做修饰；v2 通过显式 `static_cast<float>` 与 `3.1416f` 字面量消除。
