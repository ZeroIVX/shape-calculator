# 01 · 项目概述

## 定位

ShapeCalc 是一个运行在 Windows 上的轻量桌面几何计算工具，用单一可执行程序完成「选择图形 → 填入尺寸 → 得到全部相关指标」的闭环。

它不追求成为通用 CAS（计算机代数系统），也不做作图与证明，只解决一件事：**把几何量的计算从手工查公式、逐项代入中解放出来，并且对不规则图形也给出一条可操作的测量路径。**

## 目标场景

| 场景 | 具体用法 |
|---|---|
| 学习与作业验算 | 算完一道题后代入复核，确认面积/周长/体积没有用错公式或漏乘系数 |
| 教学演示 | 课堂上调整参数，即时展示同一图形的多个指标如何随尺寸联动 |
| 不规则区域估算 | 在网格画布上描出地砖、板材、地块轮廓，直接读出面积与周长 |
| 二次开发基线 | 表驱动结构便于继续接入新图形，可作为 C++/EasyX 图形程序的教学样例 |

## 解决的问题

**1. 公式分散，容易错用**

同一道题往往要同时求面积、周长、对角线。不同图形的公式形态差异大，且存在易错点：菱形面积是对角线乘积的一半而非边长乘积、圆锥表面积需要先用勾股定理求母线、三角形面积要判断三边能否成三角形。程序把这些公式内置为独立函数，一次输入、多项输出，从源头消除错配。

**2. 不规则图形无公式可套**

实际场景中的区域很少是标准形状，习惯做法是数格子估算，误差大且不可复现。程序提供网格手绘画布：鼠标逐点落笔、自动吸附格点、点击起点闭合，由鞋带公式给出精确的代数面积，周长同步累计。

**3. 验算反馈链路长**

写完一页计算再去对照答案，错误定位成本高。程序把反馈压缩到「输入完即见结果」，并对非法输入立即给出原因（如三边不满足三角形不等式），而不是输出一个 `nan` 或负数让人自行猜测。

## 形态与规模

| 项目 | 说明 |
|---|---|
| 交付形态 | 单文件 C++ 源码 + 一键批处理脚本，无安装程序、无运行库依赖（除系统自带） |
| 界面框架 | 无（不使用 MFC/Qt），全部界面由 Win32 GDI 手绘 |
| 图形库 | EasyX（封装 GDI 的轻量绘图库），随仓库内置 |
| 代码规模 | v1：233 行；v2：1296 行 |
| 构建产物 | 单个 `.exe`，x64 约 65 KB |
| 编译状态 | v2：0 错误 / 0 警告（`/W3`） |

## 设计边界

明确不做的部分，避免范围蔓延：

- 不做函数图像绘制、方程求解、符号推导
- 不做单位换算（所有长度视为同一单位，输出不带单位后缀）
- 不做数据持久化与历史记录
- 不支持自交多边形的正确面积语义（按鞋带公式代数面积计算）
