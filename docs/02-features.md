# 02 · 功能说明

共 15 类规则图形（44 项指标）与 1 个手绘多边形模式。所有长度为无单位数值，`π` 取 `3.1416`（与 v1 保持一致，便于版本对照）。

## 平面图形（9 类 / 25 项）

| 图形 | 输入参数 | 输出指标 | 公式 |
|---|---|---|---|
| 矩形 | 长 `a`、宽 `b` | 面积 S、周长 C、对角线 d | `S=ab`，`C=2(a+b)`，`d=√(a²+b²)` |
| 正方形 | 棱长 `a` | 面积 S、周长 C、对角线 d | `S=a²`，`C=4a`，`d=a√2` |
| 三角形 | 三边 `a,b,c` | 面积 S、周长 C、内切圆半径 r内、外接圆半径 R外 | `p=(a+b+c)/2`，`S=√(p(p-a)(p-b)(p-c))`，`r内=S/p`，`R外=abc/(4S)` |
| 圆形 | 半径 `r` | 面积 S、周长 C、直径 d | `S=πr²`，`C=2πr`，`d=2r` |
| 平行四边形 | 底边 `a`、高 `h`、邻边 `b` | 面积 S、周长 C | `S=ah`，`C=2(a+b)` |
| 菱形 | 对角线 `d1`、`d2` | 面积 S、边长 `a`、周长 C | `S=d1·d2/2`，`a=√((d1/2)²+(d2/2)²)`，`C=4a` |
| 梯形 | 上底 `a`、下底 `b`、高 `h` | 面积 S、中位线 `m` | `S=(a+b)h/2`，`m=(a+b)/2` |
| 扇形 | 半径 `r`、圆心角 `θ`(°) | 面积 S、弧长 L、周长 C | `S=πr²θ/360`，`L=2πrθ/360`，`C=L+2r` |
| 椭圆 | 长半轴 `a`、短半轴 `b` | 面积 S、周长 C（近似） | `S=πab`，`C≈π[3(a+b)−√((3a+b)(a+3b))]`（拉马努金近似） |

## 立体图形（6 类 / 19 项）

| 图形 | 输入参数 | 输出指标 | 公式 |
|---|---|---|---|
| 长方体 | 长 `a`、宽 `b`、高 `h` | 体积 V、表面积 S总、体对角线 d | `V=abh`，`S总=2(ab+bh+ah)`，`d=√(a²+b²+h²)` |
| 正方体 | 棱长 `a` | 体积 V、表面积 S总、体对角线 d | `V=a³`，`S总=6a²`，`d=a√3` |
| 圆柱 | 底半径 `r`、高 `h` | 体积 V、侧面积 S侧、表面积 S总 | `V=πr²h`，`S侧=2πrh`，`S总=2πr(r+h)` |
| 圆锥 | 底半径 `r`、高 `h` | 体积 V、侧面积 S侧、表面积 S总、母线 `l` | `l=√(r²+h²)`，`V=πr²h/3`，`S侧=πrl`，`S总=πr(r+l)` |
| 球 | 半径 `r` | 体积 V、表面积 S总 | `V=4πr³/3`，`S总=4πr²` |
| 圆台 | 上底 `r1`、下底 `r2`、高 `h` | 体积 V、侧面积 S侧、表面积 S总、母线 `l` | `l=√((r2−r1)²+h²)`，`V=πh(r1²+r1r2+r2²)/3`，`S侧=π(r1+r2)l` |

## 手绘不规则多边形（2 项）

点击底部「自由多边形」进入画布模式，右侧面板切换为网格画布。

| 项目 | 说明 |
|---|---|
| 画布尺寸 | 264×320 px，网格边长 20 px，共 13×16 格 |
| 单位约定 | **1 格 = 1 单位**，原点在画布左下角，向上为正方向 |
| 落点方式 | 左键点击，自动吸附到最近的网格交点 |
| 闭合方式 | 顶点数 ≥ 3 时，点击橙色起点（容差 10 px）闭合 |
| 撤销 | 右键；已闭合则先解除闭合，否则删除最后一个顶点 |
| 清空 | 「清空」按钮或 `Esc` |
| 面积公式 | 鞋带公式 `S = ½·|Σ(xᵢ·yᵢ₊₁ − xᵢ₊₁·yᵢ)|`，末点自动与首点相连 |
| 周长公式 | 已闭合时含收尾边，未闭合时按开放折线累计 |

面积在顶点数 ≥ 3 时即开始显示（视作自动闭合的预览值），周长在 ≥ 2 时显示，未达阈值显示 `—`。

## 交互约定

### 规则图形

| 操作 | 效果 |
|---|---|
| 点击左侧图形按钮 | 选中图形，光标自动落到第一个参数输入框 |
| 数字键 / `.` | 录入数值，仅允许数字与单个小数点，最长 15 字符 |
| `Backspace` | 删除末位 |
| `Tab` | 切换到下一个参数输入框 |
| `Enter` 或点击「计算」 | 计算并显示全部指标 |
| `Esc` 或点击「清空」 | 清空参数与结果 |
| 点击「复制结果」 | 按「图形名 + 参数 + 指标」写入剪贴板 |

### 手绘多边形

| 操作 | 效果 |
|---|---|
| 左键点击网格 | 落一个顶点 |
| 左键点击橙色起点 | 闭合图形 |
| 右键 | 撤销（解除闭合 / 删除末点） |
| `Esc` 或「清空」 | 清空全部顶点 |
| 「复制结果」 | 复制顶点数、面积、周长 |

## 输入校验

| 情形 | 反馈 |
|---|---|
| 参数留空 | 对应输入框标红，提示「请填写参数：xxx」 |
| 参数 ≤ 0 | 全部输入框标红，提示「参数无法构成该图形，请检查是否为正数且满足几何条件」 |
| 三角形不满足三边关系 | 同上（`a+b>c`、`a+c>b`、`b+c>a` 全部校验） |
| 扇形圆心角越界 | 要求 `0 < θ ≤ 360` |

## 结果格式

| 数值范围 | 格式 | 示例 |
|---|---|---|
| `1e-4 ≤ |v| < 1e7` | 定点 4 位小数 | `125.6637` |
| 超出上述范围 | 科学计数法 4 位小数 | `1.2345e+08` |
