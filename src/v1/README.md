# v1 · 初始版本

> ShapeCalc 的首个可运行实现：6 类平面图形，每类输出单一面积指标。

## 功能范围

| 图形 | 输入 | 输出 |
|---|---|---|
| 矩形 | 长 a、宽 b | 面积 |
| 三角形 | 三边 a、b、c | 面积（海伦公式） |
| 圆形 | 半径 r | 面积 |
| 平行四边形 | 底边 a、高 h | 面积 |
| 菱形 | 对角线 a、b | 面积 |
| 梯形 | 上底 a、下底 b、高 h | 面积 |

界面为 390×460 的单页按钮面板，8 个按钮（6 个图形 + 「显示结果」+「退出」）。点击图形后依次弹出输入框录入参数，再点「显示结果」查看数值。

## 运行

```bat
cd src\v1
run.bat
```

需要 Visual Studio 的 C++ 桌面开发工作负载；EasyX 库位于仓库 `third_party/easyx`，无需单独安装。产物输出到 `build\ShapeCalc.exe`。

完整参数（`x86` / `build` / `clean` / `-h`）见 [构建文档](../docs/05-build.md)。

## 定位

本版本作为**功能基线与重构起点**保留，不承担日常使用职责。它记录了项目最初的技术选型（EasyX + 事件循环 + 独立计算函数），也存在若干已知问题：

| 问题 | 说明 |
|---|---|
| 菱形面积公式 | 按 `a × b` 计算，漏除以 2（正确值应为对角线乘积的一半） |
| 三角形非法三边 | 海伦公式对不合法输入取 `sqrt` 得 `NaN`，`if (s < 0)` 无法拦截，最终显示 `-nan` |
| 悬停高亮残留 | 鼠标快速跨越按钮时，旧按钮的反色高亮不会被擦除 |
| 输入未校验 | `sscanf` 返回值未检查，非数字输入会沿用上一次的全局值 |
| 扩展成本高 | 新增图形需同步修改按钮表、判断链、点击分支、绘制语句四处 |
| 编译告警 | 2 条 `C4244`（double → float 隐式转换） |

这些问题在 v2 中均已处理，差异对照见 [docs/04-versions.md](../docs/04-versions.md)。

## 源码说明

单文件 `ShapeCalc.cpp`，233 行。核心结构：

- 全局变量 `a, b, c, h, r` 存放参数，`Text[100]` 存结果字符串，`result` 存数值
- 6 个计算函数 `Rect` / `Tri` / `Cir` / `Para` / `Rhom` / `Trap`
- `button_judge()` 用 if 链判断点击落在哪个按钮
- `main()` 中 `GetMouseMsg()` 阻塞取消息，`switch` 分派 `WM_MOUSEMOVE` 与 `WM_LBUTTONDOWN`
